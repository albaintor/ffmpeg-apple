# FFmpeg Apple

Reproducible FFmpeg iOS dynamic XCFramework builds from the unmodified upstream FFmpeg source.

The project will contain build scripts, CI, release artifacts, licences and an auditable provenance manifest. It does not contain Home Media Catalog's proprietary Swift code.

**Important:** a dynamic FFmpeg build alone does not make an adopting iOS app LGPL/App Store compliant. The complete linked media dependency graph, notices, and end-user library-replacement rights still require review.
